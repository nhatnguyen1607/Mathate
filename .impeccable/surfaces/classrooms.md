# Classroom learning

Mode: Operate. Extends the existing Mathate app, palette, Nunito typography, navigation and mascots. The user's detailed classroom flow fixes the content and task structure; implementation is code-led.

## Direction contract

THESIS: Teachers organize a real class and turn diagnostic results into usable group worksheets. Student progress is private; teacher results are an operational table.

OWN-WORLD: Existing theme-aware garden palette, white work areas, 14px bordered sheets, rounded Nunito and Lucide icons. A selected companion appears in student readiness and completion states.

STORY: Admin assigns teacher, teacher creates a named class and shares a five-digit code. Students join, take an eight-question timed warmup once, then practice when the teacher opens application. Teacher reviews results, groups students and exports two exercises per group.

FIRST VIEWPORT: Teacher overview combines a companion welcome, compact real counts, detailed class rows, pending preparation and a side agenda. Inside a class, its name and copyable code precede real counts, topic rows and roster, alongside a copyable invitation and a short group-practice reminder. Empty classes have topic suggestions and instructions to invite students rather than blank vertical space. A topic uses results, answer review and group worksheet tabs. Student topic shows warmup and locked/unlocked application; the quiz prioritizes a sticky timer, question navigation and large answer rows.

Student class refinement: the joined-class list has companion artwork, own published-topic and completion counts, a resume link for an in-progress warmup, and a compact explanation of the two learning phases. Inside an empty class, a companion welcome and useful waiting state replace the isolated centered placeholder. Independent self-study is explicitly labeled as outside classroom assignments. The shared workspace fills at least the viewport; main content grows so the footer stays at the bottom on short pages and follows content on long pages.

Classroom and warmup pages fill the available workspace width, using the app's responsive page gutters instead of a centered maximum-width container.

The completed warmup uses two balanced desktop columns: companion and overall result on the left, four skill results on the right. A shared bottom row holds the return action and one-attempt reminder. At narrower widths these sections stack in reading order.

FORM: Existing app extension; concept-seed not run because the workflow is specified and the visual system/composition is inherited. No replacement visual world or new asset family.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
