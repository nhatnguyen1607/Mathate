# Dashboard

Mode: Operate.

Primary task: choose a mathematical topic and difficulty, then start a guided practice session. Content hierarchy: welcome, topic catalog, optional unfinished practice, progress and personal daily goal. No fictional learning data. Anonymous users can inspect the catalog, sign in, or explicitly choose local demo mode.

Secondary paths: journey, badges, history. Admin controls live on their own route. Chat route puts the problem and conversation before mascot decoration on mobile.
