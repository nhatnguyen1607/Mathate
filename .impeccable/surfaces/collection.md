# Personal collection

Mode: Operate. Refines the existing child-friendly Mathate collection rather than replacing its visual identity.

The 24-medal catalog is shared by server and client. Four groups cover solved problems, habits, XP and topic discovery; server-controlled progress determines awards. Each compact white medal sheet contains a pastel Lucide illustration with ribbons, title, rule, explicit earned/locked state and labeled native progress. No new raster family or asset dependency.

The page fills the workspace with the app's responsive gutters. A group filter and status select precede a responsive four/three/two/one-column grid. Theme-aware filters and progress use semantic brand tokens with leaf fallbacks. Filtered empty states distinguish first-time learners, completed groups and a fully completed collection. Signed-out users get a login action; demo progress is explicitly temporary.

Browser checks: 1920px desktop, 1024px intermediate and 390px phone; leaf, violet and peach; zero, partial and complete profiles; group/status filtering; accessible names and no horizontal overflow. Preview progress is synthetic. Authentication request/refresh behavior is verified separately with controlled sessions; no real account was created for verification.
