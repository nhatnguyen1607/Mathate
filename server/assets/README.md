# Vietnamese PDF fonts

Nunito, licensed under the SIL Open Font License in `Nunito-OFL.txt`.

Source: [Google Fonts Nunito](https://github.com/google/fonts/tree/main/ofl/nunito), `Nunito[wght].ttf`, downloaded 24 November 2026. Static instances were produced with FontTools `varLib.instancer.instantiateVariableFont` at weights 500 (`Nunito-Medium.ttf`) and 800 (`Nunito-ExtraBold.ttf`). No character subsetting; Latin and Vietnamese glyph coverage is retained. These font files are used by server PDFKit, not fetched at runtime.
