# Mathate design

A small garden of mathematical discoveries for children 6–11. Quiet, welcoming task surfaces; warm personality lives in Mimo and the language. This is a new app, so Math-AI's blue classroom styling is not inherited.

- Green #347e52 anchors navigation and primary actions; background #f8faf7; ink #263c32.
- Topic colors: muted leaf green, lilac, peach, sky blue, pink and honey. Color accompanies text and icons.
- Nunito variable, locally hosted with Vietnamese glyph coverage; rounded, open counters and clear numeric forms.
- Persistent left navigation on desktop, accessible drawer on mobile. Primary dashboard contains the topic catalog and personal progress. A topic picker protects focus for the essential difficulty decision.
- 16 px base text. Compact desktop metadata is supplementary, never the sole task instruction; problem text is 17–18 px with generous leading.
- Cards use a single thin border, 12–16 px radii; shadows reserved for overlays. Mimo is a real generated transparent raster illustration. Lucide provides consistent icons.
- Mimo welcome reveal is the authored entrance; reduced-motion disables animation. The practice companion uses the same transparent Mimo image, with thinking, success, encouragement, greeting and speech states. The old Spline robot stays archived as an asset. Vietnamese female/male voice choices live under Mimo and lock while audio loads or plays.
- Visible focus rings, skip navigation, semantic labels, live feedback and focus containment on dialogs.

The Impeccable context launcher could not initialize its engine cache in this sandbox. Product context and craft guidance were read directly. The user's cute, child-friendly brief and confirmed age group govern this implementation.
